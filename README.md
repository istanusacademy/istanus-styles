# Istanus - Vancouver (No et al.) Citation Style

This repository contains the customized **Vancouver-based CSL citation style** developed by **Istanus Academy Biotechnology Co. Ltd.** for use in its academic publications, including journals, books, and congresses.

> 📌 Style name: **Istanus - Vancouver (no et al.)**  
> 📄 CSL File: `Istanus.csl`  
> 🏛 Maintained by: [Istanus Academy Biotechnology Co. Ltd.](https://istanus.com)

---

## 🔹 Key Features

- **In-text citation format:** numeric, in **round parentheses** → *(1)*, *(2,3)*  
- **No "et al."**: full author names always shown  
- **Italicized** book and journal titles  
- **DOI or URL** added at the end (no trailing period)  
- **Page range format:** minimal (e.g., 123–5)

---

## 🔹 How to Use

You can use this CSL file in any reference manager that supports CSL styles, such as **Zotero**, **Mendeley**, **JabRef**, and others.

---

### ▶️ Zotero Instructions

1. [Download the CSL file](https://raw.githubusercontent.com/istanusacademy/istanus-styles/main/Istanus.csl)
2. Open Zotero
3. Go to:  
   `Edit → Preferences → Cite → Styles → [+]`
4. Select the downloaded `.csl` file
5. Done! You can now cite using this custom style

---

### ▶️ Mendeley Desktop Instructions

1. [Download the CSL file](https://raw.githubusercontent.com/istanusacademy/istanus-styles/main/Istanus.csl)
2. Open Mendeley Desktop
3. Go to:  
   `View → Citation Style → More Styles…`
4. Click **"Get More Styles"** → **"Download style"** or **"Load from file"**
5. Select the downloaded `.csl` file and confirm
